# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and what an attacker could do with
it. You'll get a reply as soon as possible, and credit in the fix if you want it.

## Scope

In scope: the helper script, the bar widget, the udev rule and the install
steps in the README.

Out of scope: Omarchy, Quickshell, the Hollyland firmware, and anything that
already requires root or full control of the user's account.
